### About Me

I'm a Data Science & Engineering M.Sc. student at Politecnico di Torino, with a B.Sc. in Statistics for Big Data from the University of Salerno (110/110 *cum laude*). I like turning messy, real-world problems — noisy sensor signals, unstructured survey data, road-scene imagery, relational databases — into clean, well-tested pipelines with results I can actually explain.

Most of what's below started as university coursework, but I treat every project as if it had to survive a code review: refactored into reusable modules, documented, and (when the numbers matter) validated against a from-scratch or numerical ground truth rather than just "it ran."

- 🔭 Currently finishing my M.Sc. in **Data Science and Engineering** at Politecnico di Torino
- 💡 Also working on **StockPulse**, an AI-driven inventory optimization concept for Italian retail SMEs (Start Cup Piemonte Valle d'Aosta)
- 🌱 Currently deepening: Deep Learning, Statistical Learning, Big Data Analytics

### 📌 Featured Projects

**[Road Scene Segmentation & Anomaly Detection](https://github.com/francescalongo17set/road-scene-segmentation)**
Fine-tuned a COCO-pretrained transformer segmentation model (EoMT) to Cityscapes via Layer-wise Learning Rate Decay, raising mIoU from 55.1% to 79.8%, and benchmarked four anomaly-scoring methods across five open-world benchmarks. Team project, reorganized into a clean, reproducible repo.
`Python` `PyTorch` `PyTorch Lightning` `Transformers`

**[PCA & K-Means Client Profiling](https://github.com/francescalongo17set/Client-profiling)**
End-to-end unsupervised pipeline segmenting survey respondents into behavioural profiles via PCA and K-Means, with a modular Python package and an IEEE-style written report.
`Python` `Scikit-learn` `LaTeX`

**[Digital News Classification](https://github.com/francescalongo17set/Digital-News-Classification)**
Multi-class text classification over 80,000 news articles using word- and character-level TF-IDF and a tuned Linear SVM, with a reusable preprocessing module.
`Python` `Scikit-learn` `NLP`

**[Financial Database Analysis](https://github.com/grainone28/Financial-Database-Analysis)**
Relational analysis of a ~1M-record banking database — SQL-based querying, hypothesis testing, and classification modeling to predict loan default. Team project (3 people).
`Python` `SQLAlchemy` `SciPy`

**[PageRank](https://github.com/francescalongo17set/pagerank)** · **[Audio Denoising](https://github.com/francescalongo17set/Audio-Denoising-)**
Two from-scratch numerical linear algebra projects: Google's PageRank power method on a real web graph, and a Savitzky-Golay filter derived via a hand-written Householder QR factorization — both verified numerically against known ground truths.
`Python` `NumPy` `SciPy`

**[Hematopoietic Cell Classification](https://github.com/francescalongo17set/Hematopoietic-Cell-Classification)** *(Bachelor's thesis)*
Machine learning pipeline for the analysis and classification of hematopoietic cells — preprocessing, feature engineering, model selection and evaluation.
`Python` `Scikit-learn`
